      System Pipeline

      How AgriSmart Operates

      End-to-end trace from browser telemetry acquisition to mathematical Random Forest bagging inference.

      01
      Telemetry Acquisition

      User submits 7 soil macronutrient and atmospheric telemetry parameters via responsive dual controls or regional presets.

      02
      Validation Gate

      Backend Flask pipeline checks finiteness, data-types, physical boundary conditions, and flags out-of-distribution extremes.

      03
      100-Tree Bagging

      Pre-serialized Random Forest model queries 100 estimators in parallel to compute calibrated posterior probabilities across 22 crops.

      04
      Advisory Output

      Client dynamically visualizes primary crop class, ranked alternatives, agronomic season guidelines, and telemetry radar analysis.

      Ethical & Agronomic Scope

      Project Purpose & Real-World Boundaries

      Academic transparency regarding machine learning assumptions and boundaries in agricultural applications.

      Academic Contribution & Scope

      AgriSmart demonstrates an end-to-end full-stack machine learning engineering architecture for an MCA capstone project. It showcases automated data validation, 5-fold cross-validation model selection, persistent joblib serialization, and a modern glassmorphic interface without external dependencies.

      The system delivers instant diagnostic screening based on standard lab soil test assays and microclimate readings.

      Agronomic Limitations

      Model predictions reflect correlations within the empirical training dataset. Real-world farm management requires accounting for unmodeled ecological variables:

      • Market Economics: Local market demand, Minimum Support Price (MSP), and transport logistics.
      • Biological Factors: Seed hybrid varieties, pest resistance, and crop rotation history.
      • Water Governance: Irrigation infrastructure, groundwater availability, and canal schedules.
